# Generate Weekly Briefing Skill

**Silver Tier Agent Skill** - Creates the "Monday Morning CEO Briefing" as described in the hackathon documentation (lines 516-525).

---

## Description

This skill automatically analyzes the past week's business activity and generates a comprehensive CEO briefing report. It transforms the AI Employee from a task executor into a strategic business partner.

**The "Aha!" Moment**: The AI autonomously audits tasks and finances to report revenue and bottlenecks (Hackathon line 11).

---

## Usage

```
/skill generate_weekly_briefing [--week DATE] [--output-dir Briefings] [--dry-run]
```

---

## Behavior

### Standard Usage

```
/skill generate_weekly_briefing
```

**What it does:**

1. **Determine period**: By default, last Monday-Sunday (or past 7 days)
2. **Read data sources**:
   - `Business_Goals.md` - Targets and metrics
   - `Dashboard.md` - Current stats
   - `/Done/` - Completed tasks this week
   - `/Logs/` - Activity log
   - `Business_Goals.md` - Subscription audit rules
3. **Analyze metrics**:
   - Revenue this week (from accounting if available, else manual input)
   - Tasks completed vs. planned
   - Bottlenecks (tasks that took longer than expected)
   - Active projects status
   - Subscription waste detection
   - Upcoming deadlines
4. **Generate report** in `/Briefings/YYYY-MM-DD_Monday_Briefing.md`
5. **Update Dashboard** with briefing link
6. **Log generation** to `/Logs/`

## Data Sources

### 1. Completed Tasks

Scans `/Done/` for items created in past week:

- Filter: `created` date in frontmatter within last 7 days
- Extract: `TASK_*.md`, `PLAN_*.md`, `EMAIL_*.md` (sent), `WHATSAPP_*.md` (processed)
- Summarize: Count by type, key outcomes

### 2. Business Goals

Reads `Business_Goals.md`:

- Revenue targets (monthly, quarterly)
- Metric definitions (response time, payment rate)
- Active projects with deadlines
- Subscription list with audit rules

### 3. Dashboard Stats

Reads `Dashboard.md`:

- Today's activity numbers
- System health status
- Recent completions

### 4. Logs

`/Logs/` for audit trail:

- Actions performed
- Approvals granted/denied
- Errors encountered

---

## Analysis Features

### Bottleneck Detection

Identifies tasks that exceeded estimated duration:

1. Read plan in `/Plans/` or `/Done/PLAN_*.md`
2. Compare `estimated_completion` vs `actual_completion`
3. Calculate delay: `actual - estimated`
4. Highlight tasks with delay > 2 days

**Report format:**
```markdown
| Task | Expected | Actual | Delay |
|------|----------|--------|-------|
| Client B proposal | 2 days | 5 days | +3 days |
```

---

### Subscription Auditing

Applies rules from `Business_Goals.md`:

```yaml
subscription_audit:
  flag_if:
    - no_activity_days: 30
    - cost_increase_pct: 20
    - duplicate_tools: true
```

Checks bank transactions (if accounting integrated) or manual tracking.

**Output:**
```markdown
### Cost Optimization
- **Notion**: No login in 45 days. $15/mo → Consider canceling
- **Adobe**: Cost increased 25% (was $20, now $25) → Flag for review
```

---

### Deadline Tracking

From `Business_Goals.md` active projects:

- Calculate days remaining
- Flag overdue items
- Highlight coming due (within 7 days)

## Configuration

In `Company_Handbook.md`, add:

```yaml
weekly_briefing:
  day: "monday"
  time: "07:00"  # 7 AM
  send_to: []     # Email addresses to send briefing to
  include:
    - revenue
    - tasks
    - bottlenecks
    - subscriptions
    - deadlines
  template: "default"  # or "detailed", "executive"
```

## Scheduling

Use the **Scheduler** (Silver Tier) to run automatically:

```yaml

  schedule:
    minute: "0"
    hour: "7"        # 7 AM Monday
    weekday: "1"     # Monday
  action:
    type: "claude_skill"
    skill: "generate_weekly_briefing"
    working_dir: "AI_Employee_Vault"
```

---

## Error Handling

- **No data**: If no tasks completed, still generate with "quiet week" note
- **Missing Business_Goals.md**: Use defaults, flag error in report
- **Log parsing errors**: Log warning, continue
- **File write errors**: Create in temp location, alert human
